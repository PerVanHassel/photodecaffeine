# Skills van buiten

De mappen hiernaast komen uit [tasteskill/tasteskill](https://github.com/tasteskill/tasteskill)
(MIT-licentie), map `skills/`, opgehaald op 11 september 2026.

Het zijn ontwerprichtlijnen voor frontend werk — hoe een pagina eruit hoort te
zien, wat je niet moet doen, welke typografie en beweging. Ze schrijven geen
code uit zichzelf en draaien niets; ze sturen alleen hoe een ontwerp gemaakt
wordt. Elke skill wordt pas gebruikt als het werk erbij past.

Bijwerken: haal de nieuwe versie op uit die repo en vervang de mappen.
Eigen skills voor dit project zet je hier gewoon naast, in een eigen map met
een `SKILL.md`.
